# Windows-Server-Active-directory-Homelab
Hands on Windows server home lab featuring Active directory, DNS, DHCP, HyperV, Networking configuration and troubleshoting next will be user account management, group policy and more troubleshooting exercises 


## Project Overview
I built a Windows Server lab in Hyper-V with Active Directory, DNS, and DHCP, then troubleshot client connectivity issues.

## Tasks Completed
- built built Hyper-V lab with Windows Server and Windows 11 client
- configured active directory and promoted the server to domain controller
- configured dhcp scope and authorized it in AD
- released and renewed "client" ip
- Verified connectivity with ping and dns lookups
- troubleshot ping failure and reviewed windows firewall rules
- documented intermittent DNS timeouts
